# SOLRAK v0.1.97 — referencia visual de Detalle de Ventas

Contrato visual tomado de la referencia suministrada para Suma Punto de Venta, implementado con código propio de SOLRAK:

- barra superior naranja con título `Detalle de Ventas`;
- panel lateral con `HOY`, `ESTE MES`, `ESTE AÑO`, rango de fechas, turno, categoría, usuario, `BUSCAR` y `CERRAR`;
- visor de reporte con navegación de páginas, actualizar, imprimir, exportar, zoom y búsqueda;
- hoja blanca con marca SOLRAK, fecha/hora, `Reporte de Ventas` y `Resumen`;
- gráfica de ventas por periodo;
- tabla de totales con ventas, devoluciones, cancelaciones, ventas netas y ganancias;
- tabla por periodo;
- `Detalle de Ventas` con columnas: Ticket, Fecha, Nombre del Producto, Categoría, Dev., Canc., Mayr., Pr. Costo, Pr. Mayr., Pr. Pub., % Desc., Cant., UM y Total.

El módulo consulta el API real de reportes existente (`summary` y `detail`) y no modifica inventario, precios, existencias ni datos fiscales.
